Connect this phone

Control your laptops from anywhere — any network, end-to-end encrypted, nothing to install on this device.

Invitation for a laptop

  1. Send this invitation to the laptop (e-mail, Viber, WhatsApp…).
  2. On that laptop: open the link, download the file, start it, and click Yes when it asks.
  3. Laptop Remote already runs there? Type A in its window and paste the invitation.

Waiting for the laptop… You can close this page; the invitation waits for 7 days.

  2. Its window shows a code like K7PQ-4XMZ. No code there? Type L in the window and press Enter.

You type the code only once (it works once, for 15 minutes). After that this phone stays connected — no PIN, no code.

On iPhone, a page added to the home screen has its own memory: open the icon and do this there. Private mode, or a browser that deletes its data (like the DuckDuckGo flame button), forgets the connection.

    Tips

    Like an app: add this page to your home screen (Chrome: menu ⋮ → Add to Home screen; Safari: share □↑ → Add to Home Screen). On iPhone the icon has its own memory: open it once and type a new code from the laptop there.

    Another laptop: start Laptop Remote on it and type its code on this phone. Each laptop gets its own page and icon.

    Like an app: add this page to your home screen (Chrome: menu ⋮ → Add to Home screen; Safari: share □↑ → Add to Home Screen). On iPhone the icon has its own memory: add your laptops inside the icon (a new invitation each).

    Another laptop: “Add another laptop” above. All your laptops are in the list at the top.

    Always reachable: the laptop must be on, with internet, and someone signed in to Windows. On the charger it does not go to sleep by itself while Laptop Remote runs; set closing the lid to “Do nothing” if it is closed.

    Away from home: open bogdandata.github.io/laptop-remote — control from anywhere, encrypted (see the README).

    Encrypted: everything is locked on this device and opened only on the laptop. The tunnel and the message service see only locked data.
