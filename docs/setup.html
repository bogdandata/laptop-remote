Laptop Remote

Someone invites this laptop to Laptop Remote, to help you from far away: to see the screen and use the mouse and the keyboard. Everything is end-to-end encrypted.

Open this link on the Windows laptop that should be helped. This device is not a Windows computer.

  1. Downloaded: LaptopRemote-setup.cmd
    A small file made for this invitation only.
  2. Open the downloaded file — at the top or bottom of the browser, or in the Downloads folder. If the browser warns about the file, choose Keep (Edge: … → Keep → Show more → Keep anyway). If Windows shows “Windows protected your PC”: click More info, then Run anyway. No Run anyway? Right-click the file → Properties → tick Unblock → OK, and open it again.
  3. A black window sets everything up (a minute or two). When the laptop asks “Allow … to control this laptop from anywhere?”, click Yes. Click Yes only if you know this person and you want their help.
  4. Done. You can minimize the black window, but do not close it. Leave the laptop on, with internet. Laptop Remote also starts by itself (minimized) every time you sign in to Windows.
Laptop Remote already runs on this laptop?

Then you need no download: click its window, type A, press Enter, paste this invitation and press Enter.

What does the setup do?
  • Everything goes into one folder, %LOCALAPPDATA%\LaptopRemote. No administrator rights are needed, and nothing else on the laptop is changed.
  • It downloads, from the official places only: Laptop Remote (open source, github.com/bogdandata/laptop-remote), a private copy of Python (python.org), and Cloudflare's tunnel program cloudflared (github.com/cloudflare).
  • Only the device that made this invitation gets access, and only if you click Yes. Cloudflare and the message service in between see only encrypted data.
  • To end the help: close the Laptop Remote window (it starts again when you sign in next time). To remove it completely: uninstall.bat in %LOCALAPPDATA%\LaptopRemote\app.

Laptop Remote — open source on GitHub. This page sends nothing anywhere: the invitation stays in this browser until you download the setup.
